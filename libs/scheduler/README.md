# scheduler

자동 스케줄 실행 모듈입니다. 서버 실행 중(`nx serve api`)일 때 Cron 작업으로 동기화/추천/결과 발송을 수행합니다.

## Cron 목록 (Asia/Seoul)

- `30 12 * * 1` - 월 12:30: 로또 추천 생성 후 텔레그램 발송
- `0 22 * * 6` - 토 22:00: 로또 결과 체크 후 텔레그램 발송
- `30 22 * * 6` - 토 22:30: 로또 당첨 데이터 동기화(통계용)
- `0 12 * * 5` - 금 12:00: 연금 결과 체크 후 텔레그램 발송
- `30 12 * * 5` - 금 12:30: 연금 추천 생성 후 텔레그램 발송
- `0 13 * * 5` - 금 13:00: 연금 당첨 데이터 동기화(통계용) + 동기화 결과 알림

## 동작 메모

- 추천 Cron은 해당 회차 추천 데이터가 이미 있으면 생성/발송을 스킵합니다.
- 결과 Cron은 해당 회차에 추천 데이터가 없으면 발송하지 않습니다.
